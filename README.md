# 💬 Chat Bot — Projeto de Front-end

Projeto acadêmico desenvolvido como parte de um Checkpoint de Front-end, com foco no desenvolvimento de uma aplicação de chatbot.

**Repositório:** [github.com/AlexandreFerreiraaa/chat_bot](https://github.com/AlexandreFerreiraaa/chat_bot)

## 📌 Sobre o projeto

O Chat Bot é um projeto desenvolvido no contexto acadêmico para aplicar conhecimentos de desenvolvimento de interfaces e organização de aplicações.

O repositório está organizado em duas áreas principais, `frontend` e `backend`, permitindo separar a interface do usuário da lógica de processamento da aplicação.

Esta documentação apresenta a estrutura do projeto, seus objetivos e as orientações para instalação e execução, que devem ser ajustadas de acordo com as tecnologias e os arquivos implementados.

## 🎯 Objetivos

- Desenvolver uma aplicação com interface organizada e intuitiva.
- Aplicar conceitos de desenvolvimento Front-end.
- Organizar o código em módulos e pastas.
- Integrar, quando previsto na implementação, a interface com a lógica de processamento.
- Praticar o uso do Git e do GitHub para versionamento e colaboração.

## 🗂️ Estrutura do projeto

```text
chat_bot/
├── backend/
├── frontend/
├── .gitignore
└── README.md
```

### `frontend/`

Diretório destinado aos arquivos responsáveis pela interface da aplicação, incluindo os componentes visuais e a interação com o usuário, conforme a implementação do projeto.

### `backend/`

Diretório destinado à lógica de processamento e aos recursos de suporte da aplicação, conforme os módulos existentes.

### `.gitignore`

Arquivo utilizado para indicar quais arquivos e diretórios devem ser ignorados pelo Git.

### `README.md`

Documento com as informações principais sobre o projeto, sua organização e suas instruções de utilização.

## 🛠️ Tecnologias utilizadas

As tecnologias e versões devem ser documentadas após a verificação dos arquivos de configuração do projeto.

- **Front-end:** identificar conforme os arquivos da pasta `frontend`.
- **Back-end:** identificar conforme os arquivos da pasta `backend`.
- **Versionamento:** Git e GitHub.

## ⚙️ Pré-requisitos

Antes de executar o projeto, verifique as tecnologias exigidas pela aplicação.

1. Git instalado.
2. Visual Studio Code ou outro editor compatível.
3. Runtime, interpretador ou gerenciador de pacotes exigido pelo projeto.
4. Dependências descritas nos arquivos de configuração.

## 🚀 Como executar

### 1. Clonar o repositório

Abra o terminal e execute:

```bash
git clone https://github.com/AlexandreFerreiraaa/chat_bot.git
```

### 2. Acessar a pasta

```bash
cd chat_bot
```

### 3. Abrir no Visual Studio Code

```bash
code .
```

### 4. Instalar as dependências

Consulte os arquivos de configuração de cada parte do projeto para identificar o gerenciador de pacotes e executar os comandos corretos de instalação.

### 5. Iniciar a aplicação

Execute os comandos de inicialização definidos para o `frontend` e o `backend`, quando ambos forem necessários.

> **Nota:** os comandos específicos de instalação e inicialização precisam ser confirmados nos arquivos do repositório antes de serem considerados definitivos.
